About
I write systems software in Rust because correctness and speed shouldn't be a trade-off. The compiler catches what other languages let ship.

My focus is the layer most people never see: networking stacks, async runtimes, CLI tooling and game modifications — the kind of performance-critical code where a wrong allocation means a dropped frame or a leaked connection.

No garbage collector. No data races. No undefined behavior. Ownership and the borrow checker do the heavy lifting at compile time, so software stays fast and predictable under real load — with architecture as clean as the syntax.
